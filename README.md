# Gestão de Carteira CS — telas (Disktrans)

Site estático do painel de Customer Success, publicado no GitHub Pages.

- **Este repositório tem só as telas (HTML, CSS e JS).** Não há dados de clientes nem
  senhas aqui: os números ficam num pacote **criptografado** no Supabase (bucket privado),
  que só a conta da equipe, com a senha da equipe, consegue baixar e abrir.
- Código-fonte completo, pipeline de dados e documentação: repositório privado
  `JaquelineDisktrans/Carteira-CS` (pasta `front/`). Altere lá e copie para cá.
- `js/config.js` contém só configuração pública (URL e chave publicável do Supabase).

Responsável: Customer Success Disktrans.
